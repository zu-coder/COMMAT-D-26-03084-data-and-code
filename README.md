# COMMAT-D-26-03084-data-and-code
Data and molecular dynamics simulation codes for manuscript COMMAT-D-26-03084.

## Manuscript title

**Effect of melt temperature on the wetting and interfacial adhesion of
molten Fe–3 wt.% Si alloy droplets: A molecular dynamics study**

## Description

This repository contains the molecular dynamics simulation input files,
initial atomic configurations, interatomic potential files, and
post-processing scripts used in the manuscript.

## Repository contents

- `Lammps_inputs/`: LAMMPS input scripts and restart files used for the simulations.
- `Initial_structures/`: Initial atomic configurations used to construct the simulation systems.
- `Postprocessing_scripts/`: Python scripts used for displacement-vector, contact-angle, and spreading-radius analyses.
- `Potential_files/`: MEAM interatomic potential files used in the simulations.

## Software

The calculations and post-processing were performed using:

- LAMMPS
- Python 3
- NumPy
- Matplotlib

## Data and code availability

The simulation input files, initial configurations, interatomic potential
files, and post-processing scripts used in this study are provided in this
repository.

Complete atomic trajectory files are not included because of their large
file sizes. They are available from the corresponding author upon
reasonable request.
